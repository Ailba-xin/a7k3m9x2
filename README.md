# Q币余额表 · 独立手机版

手机浏览器直接查 Q币余额，**不需要电脑开机**、不需要服务器、不需要任何费用。

## 怎么用

1. 手机打开网址（GitHub Pages 地址）
2. 点右上角「导入CK」
3. 先在电脑版 Q币余额表里：**右键账号表 → 复制全部 CK（导出给独立手机版）**
4. 把复制到的内容粘贴进去 → 点「导入」
5. 自动查询所有账号，显示余额

## 特点

- 直连腾讯接口（JSONP），手机自己查，不经过任何服务器
- 数据（账号票据）只存在手机浏览器本地，不上传
- 每 5 分钟自动刷新；下拉到页面顶部再往下拉 = 手动刷新
- 支持隐藏 QQ 号
- 电脑关机也能用

## 更新

页面在 GitHub Pages 上，改完推送后手机打开自动更新（Service Worker 用网络优先策略）。
